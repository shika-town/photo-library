# 担当者マニュアル：フォトライブラリー管理画面

SHIKA PHOTO LIBRARY の写真情報を、スプレッドシートの列を直接触らずに編集するための手順です。
専門知識がなくても、この画面から写真の登録・修正・公開ができるように作られています。

## 🔗 よく使うリンク

| 何を開きたいか | リンク |
|---|---|
| 公開サイト（できあがったホームページ） | <https://shika-town.github.io/photo-library/> |
| 運用スプレッドシート（写真・スポットの元データ） | <https://docs.google.com/spreadsheets/d/1A9_xzFMdD-UhKyo_a7xJ2h-5cM-orZ_giXX41ZiKT3Y/edit> |
| 管理画面（写真登録・承認・スポット編集） | スプレッドシート上部メニュー「フォトライブラリー管理」→「入力画面を開く」（下記参照） |
| 今すぐサイトに反映させたいとき | <https://github.com/shika-town/photo-library/actions/workflows/publish.yml> →「Run workflow」 |
| GitHubリポジトリ（普段は触りません） | <https://github.com/shika-town/photo-library> |

>
> **管理画面（単独URL）：** `（設置済みのURLをここに書いてください）`

設置がまだの場合は [`../02_管理者向け/管理画面_設置手順.md`](../02_管理者向け/管理画面_設置手順.md) を見てください。

## 使う画面

管理者から共有された「フォトライブラリー管理画面」のURLを開くか、
スプレッドシートから開く場合は、運用シート上部の「フォトライブラリー管理」→「入力画面を開く」を押します。

画面は4つのタブに分かれています。

| タブ | できること |
|---|---|
| 🆕 写真登録 | 新しい写真を非公開で登録する（複数枚・フォルダごとの一括登録も可） |
| 🖼️ 写真管理 | 既存写真の表示ON/OFF、ダウンロード対象ON/OFF、キャプション、説明、タグ、並び順を直す |
| ✅ 承認 | 未公開の写真やフォーム投稿を確認して公開待ちにする |
| 📍 スポット | 観光スポットの説明文や代表写真を直す・新しいスポットを追加する |

## 基本ルール

- 保存しても、すぐに公開サイトへ出るとは限りません。
- 公開サイトへの反映は、平日9時・12時・17時の自動更新、または管理者による手動更新後です（上の「今すぐ反映させたいとき」のリンクから自分で実行することもできます）。
- 写真を消したいときは、削除ではなく「公開サイトに表示する」をOFFにします。
- ダウンロードさせたい写真だけ「ダウンロード対象にする」をONにします。

## 写真を登録する（1枚〜まとめて）

1. 「写真登録」タブを開きます
2. 「写真を選ぶ（複数可）」または「フォルダを選ぶ」で写真を選びます
   - 1枚だけならタイトルを直接入力する画面のまま、2枚以上選ぶと写真ごとにタイトルを直せるリストに変わります
   - すでにGoogleドライブに置いてある写真は、ファイルを選ばずに「Googleドライブの共有リンクまたはID」に貼り付けます
3. スポットを選びます。選ぶと右側にそのスポットの代表写真が出るので、**選んだスポットで合っているか必ず確認してください**
   - どのスポットにも当てはまらない写真は「その他（分類なし）」を選べます。あとで正しいスポットが決まったら「写真管理」タブから直せます
4. 季節・切り抜き位置・タグ・表示場所・説明を必要に応じて入力します（下の「入力項目の意味」を参照）
5. 「登録」ボタン（1件なら「1件を登録」、複数なら「◯件をまとめて登録」）を押します

登録した写真は**最初から非公開**です。「承認」タブで確認してから公開してください。
複数枚まとめて登録した場合は、1枚ずつ順番に登録され、終わると「◯件登録しました」と出ます。途中で失敗した写真があれば、失敗した理由と一緒に知らせます。

### 入力項目の意味

| 項目 | 意味 |
|---|---|
| スポット | どの観光スポットの写真か。わからない・当てはまらない場合は「その他（分類なし）」でOK |
| 季節 | 写真が撮られた季節（任意） |
| 切り抜き位置 | サイトの表示枠に合わせて写真は自動でトリミングされます。人物や建物・灯台など縦に長い被写体が上下で切れてしまうときに「上寄り」「下寄り」を選びます。迷ったら「中央」のままでOK |
| タグ | 検索に使われることば。複数選べます |
| 表示場所（新着） | ONにすると、トップページの「新着」欄に表示されます（先頭6枚まで）。それ以外の「シーン」「季節」のチェックは、今のところサイトの見た目には反映されないメモ用の項目です。トップページの「シーンで探す」「季節から探す」の代表写真を差し替えたいときは管理者にご相談ください |
| 撮影者 | 通常は「志賀町」のままでOK |
| 並び順 | 数字が小さいほど一覧の前の方に表示されます。迷ったら初期値の9000のままでOK。同じスポットの写真同士で10,20,30…のように間隔を空けて振ると、あとで間に写真を挟みやすくなります |

## 写真を探して編集する

1. 「写真管理」タブを開きます
2. 「写真を検索」に、写真ID・キャプション・スポット名のどれかを入力します
   - フィルターチップ（すべて／公開中のみ／非公開のみ／DL対象外のみ）や、スポットの絞り込みも使えます
3. 表示されたサムネイル一覧から対象写真をクリックします
4. プレビュー画像を見て、正しい写真か確認します
5. 必要な項目を直します
6. 「保存」を押します

## 表示ON/OFFの使い分け

| 項目 | ON | OFF |
|---|---|---|
| 公開サイトに表示する | サイトに出ます | サイトに出ません |
| ダウンロード対象にする | 写真一覧・スポットページに出ます | 写真一覧・スポットページに出ません |

通常、サイトに出してダウンロードさせる写真は、両方ONにします。
権利確認中・人物写り込み確認中・公開を迷う写真は、まず「公開サイトに表示する」をOFFにしてください。

## キャプションを直す

1. 「写真管理」タブで写真を選びます
2. 「キャプション」を書き換えます
3. 「保存」を押します

キャプションは、写真カードやスポットページの写真下に出る短い文言です。
長すぎる文章は避け、写真を見分けられる名前にしてください。

例：

| よい例 | 避けたい例 |
|---|---|
| 夕暮れの巌門 | とてもきれいな写真 |
| 雪化粧の旧福浦灯台 | 写真1 |
| 増穂浦海岸の夕陽 | いい感じの海 |

## 説明を直す

「説明」は、写真の補足や代替テキストとして使います。
空欄でも公開できますが、写真の内容がわかる短い説明があると親切です。

## タグを直す

タグは検索に使われます。カンマ区切りで入力します。

例：

```text
夕陽,海,岩
```

よく使うタグ：

```text
夕陽,海,岩,砂浜,空撮,雪,紅葉,花,祭り,ライトアップ,建築,庭園
```

## 未確認の写真を承認する

「承認」タブには、「公開サイトに表示する」がOFFになっている写真が並びます。一覧は2つに分かれています。

| グループ | 内容 |
|---|---|
| 🆕 新規登録・未確認 | まだ誰も確認していない、登録されたばかりの写真 |
| 🙈 確認済み・非公開のままの写真 | 一度確認した上で「非公開のままにする」を選んだ写真 |

- 「✅ 公開する」を押すと、その写真は公開待ちになります
- 「非公開のままにする」を押すと、「確認済み・非公開」の一覧に移り、以後は新規扱いで催促されなくなります（削除はされません）
- 公開しないと決めた写真をあとで公開したくなったら、「確認済み・非公開」の一覧からいつでも「公開する」を押せます

## スポットの説明文を直す・新しいスポットを追加する

1. 「スポット」タブを開きます
2. 編集するスポットを選びます
3. キャッチコピーや説明文を修正します
4. 大きな写真（代表写真）を変える場合は「大きな写真のID」に写真IDを直接入力するか、「🖼️ 写真から選ぶ」ボタンでサムネイルを見ながら選びます
   - 入力すると右側にプレビューが出るので、正しい写真か必ず確認してください
5. 「保存」を押します

### 新しいスポットを追加する

これまで無かった観光スポットを新しく登録したいときは、「編集するスポット」の下の
**「➕ 新しいスポットを追加」**を押します。

1. スポット名を入力します（例：安津見海岸）
2. ID（半角英数字・ハイフンのみ）を入力します。名前を入れると自動で候補が入るので、基本はそのままで大丈夫です。ページのURLに使われるため、あとから変えないでください
3. エリアを入力します（任意）
4. 「追加する」を押します

追加した直後は非公開です。続けてキャッチコピー・説明文・代表写真を入力し、公開の準備が整ってから公開してください。

## 反映されたか確認する

保存後、次のいずれかで公開サイトに反映されます。

- 平日9時・12時・17時の自動更新
- 上の「🔗 よく使うリンク」にある GitHub Actions のリンクから、自分で今すぐ反映させる

反映後、公開サイトを開いて次を確認してください。

| 確認項目 | 見るところ |
|---|---|
| 写真が出ているか | トップページ、写真一覧、スポットページ |
| キャプションが正しいか | 写真カード、スポットページ |
| ダウンロードできるか | 写真詳細ページ |
| 出してはいけない写真が消えているか | 写真一覧、スポットページ |

公開サイト：<https://shika-town.github.io/photo-library/>

## 困ったとき

| 症状 | 対応 |
|---|---|
| 写真が探せない | 検索語を短くします。スポット名や写真IDで探します。フィルターチップが「非公開のみ」等になっていないか確認します |
| プレビューが出ない | 写真のDrive共有設定、または公開済み画像の有無を管理者に確認します |
| 保存後にサイトが変わらない | 自動更新時刻まで待つか、GitHub Actionsから手動実行します |
| 間違えて公開した | すぐに「公開サイトに表示する」をOFFにして保存し、GitHub Actionsから手動実行するか管理者に依頼します |
| どのスポットか分からない写真がある | 無理に既存スポットへ入れず「その他（分類なし）」を選びます |
| どれを触ってよいかわからない | 変更せず、管理者に確認します |

## やってはいけないこと

- スプレッドシートの1行目の見出しを変更しない
- `id` や `driveFileId` を直接書き換えない
- 列を削除しない
- 権利確認ができていない写真を公開しない
- 人物が大きく写っている写真を確認なしで公開しない
- スポットのIDは、追加したあとに変更しない（ページのURLが変わってしまいます）

迷ったら、削除ではなく非表示にしてください。
