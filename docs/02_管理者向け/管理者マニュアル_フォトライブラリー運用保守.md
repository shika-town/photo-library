# 管理者マニュアル：フォトライブラリー運用保守

SHIKA PHOTO LIBRARY の管理画面、Googleスプレッドシート、GitHub Actions、公開サイトを保守するためのマニュアルです。

## 管理対象

| 項目 | 内容 |
|---|---|
| 公開サイト | <https://shika-town.github.io/photo-library/> |
| GitHubリポジトリ | <https://github.com/shika-town/photo-library> |
| 運用シート | Googleスプレッドシート `運用シート_SHIKA_PHOTO_LIBRARY` |
| 管理画面 | Apps Script のサイドバー、またはWebアプリ |
| 写真置き場 | Googleドライブの写真フォルダ |

## 全体の仕組み

```text
担当者が管理画面で保存
        ↓
Googleスプレッドシートに反映
        ↓
GitHub Actions がシートを読み込む
        ↓
画像を取得・リサイズ
        ↓
HTMLとJSONを生成
        ↓
GitHub Pages に公開
```

公開サイトは、GitHub Actionsが成功した場合だけ更新されます。
失敗した場合、原則として直前の公開状態が残ります。

### 管理者に必要な権限

| 対象 | 権限 |

## 管理画面を更新する

ローカルの最新版は次の2ファイルです。

| Apps Script側 | ローカルファイル |
|---|---|
| `管理画面.gs` | `site/scripts/gas/管理画面.gs` |
| `管理画面.html` | `site/scripts/gas/管理画面.html` |

更新手順：

1. Apps Scriptを開きます
2. `管理画面.gs` を開きます
3. ローカルの `site/scripts/gas/管理画面.gs` の内容で丸ごと貼り替えます
4. `管理画面.html` も同様に貼り替えます
5. 保存します
6. Webアプリを使っている場合は新バージョンをデプロイします

## Webアプリをデプロイする

1. Apps Script右上の「デプロイ」を押します
2. 「新しいデプロイ」を押します
3. 種類で「ウェブアプリ」を選びます
4. 説明に内容を入れます
5. 実行するユーザーは「自分」を選びます
6. アクセスできるユーザーは運用方針に合わせて選びます
7. 「デプロイ」を押します
8. 表示されたURLを担当者に共有します

既存URLを維持したまま更新する場合：

1. 「デプロイ」→「デプロイを管理」
2. 対象デプロイの鉛筆アイコンを押します
3. バージョンを「新バージョン」にします
4. 「デプロイ」を押します

## 管理画面の主な設定値

`site/scripts/gas/管理画面.gs` の先頭付近にあります。

| 変数 | 内容 |
|---|---|
| `ADMIN_MENU_NAME` | スプレッドシート上部に出るメニュー名 |
| `DEFAULT_SHEET_ID` | Webアプリから開く対象スプレッドシート |
| `PUBLIC_SITE_URL` | 公開済み画像プレビューの参照先 |

運用シートを差し替える場合は、`DEFAULT_SHEET_ID` を新しいシートIDに変更します。

## 写真の表示制御

公開サイトに写真が出る条件は次のとおりです。

```text
publish が TRUE
かつ
downloadAllowed が TRUE
```

| 列 | 意味 |
|---|---|
| `publish` | 公開サイトに表示するか |
| `downloadAllowed` | ダウンロード対象として扱うか |

管理画面上では次の名前で表示しています。

| 管理画面 | シート列 |
|---|---|
| 公開サイトに表示する | `publish` |
| ダウンロード対象にする | `downloadAllowed` |

`downloadAllowed` 列がない場合、管理画面を開いた時に自動で追加され、既存写真は `TRUE` になります。

## 公開サイトを手動更新する

1. GitHubリポジトリを開きます
2. 「Actions」タブを開きます
3. 左の「サイトを更新して公開」を選びます
4. 「Run workflow」を押します
5. 緑の「Run workflow」を押します
6. 実行結果が緑のチェックになるまで待ちます

赤いエラーになった場合は、該当実行を開いてログを確認します。

## よくあるエラーと対応

| 症状 | 原因候補 | 対応 |
|---|---|---|
| 管理画面のメニューが出ない | Apps Scriptが保存されていない、または別プロジェクトに入れている | Apps Scriptを保存し、スプレッドシートを再読み込み |
| WebアプリURLで開けない | デプロイされていない、権限不足、Googleアカウント違い | デプロイ設定とログインアカウントを確認 |
| 写真プレビューが出ない | Drive共有設定、driveFileId不備、公開画像未生成 | Driveリンクと公開済み画像を確認 |
| 保存できない | シート列名変更、権限不足 | 1行目の見出しと編集権限を確認 |
| サイトに反映されない | Actions未実行、Actions失敗 | GitHub Actionsを確認 |
| Actionsが赤になる | シート共有、列名変更、画像ファイル不正 | ログのエラー行を確認 |
| 写真が急に減った | publish/downloadAllowedの一括変更、シート読み込み不備 | シートを確認し、必要なら直前の状態に戻す |

## GitHub Desktopで変更を反映する

ローカルファイルを直した場合は、GitHub Desktopで次を行います。

1. 変更ファイルにチェックを入れます
2. Summaryに変更内容を書きます
3. 「Commit to main」を押します
4. 「Push origin」を押します
5. GitHub Actionsが緑になるか確認します

今回の管理画面関連でよく変更するファイル：

```text
site/scripts/gas/管理画面.gs
site/scripts/gas/管理画面.html
docs/02_管理者向け/管理画面_設置手順.md
docs/01_担当者向け/担当者マニュアル_フォトライブラリー管理画面.md
docs/02_管理者向け/管理者マニュアル_フォトライブラリー運用保守.md
```

`.gitignore` のような関係ない変更は、内容がわからなければコミットしないでください。

## 担当者へ共有するもの

担当者には次だけ渡せば運用できます。

- 管理画面WebアプリURL
- `docs/01_担当者向け/担当者マニュアル_フォトライブラリー管理画面.md`
- 公開サイトURL
- 問い合わせ先

GitHubのURLやApps Scriptの編集画面は、通常は共有不要です。

## 運用ルールのおすすめ

| 項目 | 推奨 |
|---|---|
| 新規写真 | 必ず非公開で登録し、確認後に公開 |
| 権利確認中の写真 | `publish` をFALSE |
| ダウンロード不可の写真 | `downloadAllowed` をFALSE |
| 反映確認 | 公開後にトップ、写真一覧、該当スポットを確認 |
| 手動更新 | 急ぎの時だけ管理者が実行 |
| 定期確認 | 月1回、非公開写真と承認待ちを棚卸し |

## バックアップと復旧

### スプレッドシート

Googleスプレッドシートの変更履歴から戻せます。

1. 「ファイル」→「変更履歴」→「変更履歴を表示」
2. 戻したい時点を選びます
3. 内容を確認して復元します

### GitHub

GitHub DesktopまたはGitHubの履歴から、過去のコミットを確認できます。
公開サイトに問題が出た場合は、まずActionsの失敗ログと直近コミットを確認します。

### 写真

Drive上の写真を削除した場合は、Driveのゴミ箱から復元できることがあります。
完全削除した写真は復元できないため、削除より非表示を優先してください。

## 管理者チェックリスト

月1回程度、次を確認してください。

| 確認 | 項目 |
|---|---|
| □ | GitHub Actionsが定期実行で成功している |
| □ | 管理画面Webアプリが開ける |
| □ | 承認待ち写真が溜まりすぎていない |
| □ | `publish` がFALSEの写真に理由がある |
| □ | `downloadAllowed` がFALSEの写真に理由がある |
| □ | 写真フォルダの容量に余裕がある |
| □ | 担当者の権限が最新の体制に合っている |

## 緊急時の対応

出してはいけない写真が公開された場合：

1. 管理画面で対象写真を検索します
2. 「公開サイトに表示する」をOFFにします
3. 保存します
4. GitHub Actionsを手動実行します
5. 公開サイトから消えたことを確認します

管理画面が使えない場合：

1. スプレッドシートの「写真」タブを開きます
2. 対象行の `publish` を `FALSE` にします
3. GitHub Actionsを手動実行します

この対応で、写真一覧・スポットページ・写真ページの生成対象から外れます。
