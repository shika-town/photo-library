# フォトライブラリー管理画面 設置手順

スプレッドシートの列を直接触らずに、写真登録・承認・スポット説明の修正ができる入力画面です。
公開中のホームページには直接触れず、今までどおり次回の自動更新で反映されます。

## できること

| 画面 | 内容 |
|---|---|
| 写真登録 | 写真ファイル（複数選択・フォルダ一括選択も可）またはGoogleドライブ共有リンクから、非公開状態で写真を追加。スポットを選ぶと代表写真のプレビューが出て、取り違えを防げる |
| 写真管理 | 表示ON/OFF、ダウンロード対象ON/OFF、キャプション、説明、タグ、並び順を編集。フィルターチップ・スポット絞り込みで目的の写真を探しやすい |
| 承認 | フォーム投稿や未公開写真を「新規登録・未確認」「確認済み・非公開」に分けて表示し、公開待ちに変更 |
| スポット | 観光スポットのキャッチコピー・説明文・代表写真を編集。新しいスポットの追加も画面から可能 |

担当者向けの詳しい操作手順は [`../01_担当者向け/担当者マニュアル_フォトライブラリー管理画面.md`](../01_担当者向け/担当者マニュアル_フォトライブラリー管理画面.md) を参照してください。

## 設置する場所

Googleスプレッドシートの「拡張機能」→「Apps Script」に、次の2ファイルを追加します。

| Apps Script側のファイル名 | コピー元 |
|---|---|
| `管理画面.gs` | `site/scripts/gas/管理画面.gs` |
| `管理画面.html` | `site/scripts/gas/管理画面.html` |

すでに `フォルダ取り込み.gs` を設置している場合は、その同じApps Scriptプロジェクトに追加してください。
`SHEET_ID` と `PHOTO_FOLDER_ID` は既存の設定をそのまま使えます。

## 初回の開き方

1. Apps Scriptで保存します
2. スプレッドシートを再読み込みします
3. 上部メニューに「フォトライブラリー管理」が出ます
4. 「入力画面を開く」を押します
5. 初回だけ権限確認が出るので、内容を確認して許可します

## Webアプリとして独立して開く

サイドバーではなく、URLで管理画面だけを開きたい場合は Apps Script でデプロイします。

1. Apps Script 右上の「デプロイ」→「新しいデプロイ」を押します
2. 種類の選択で「ウェブアプリ」を選びます
3. 説明に「フォトライブラリー管理画面」と入れます
4. 実行するユーザーは「自分」を選びます
5. アクセスできるユーザーは「自分のみ」または「組織内の全員」を選びます
6. 「デプロイ」を押します
7. 表示されたウェブアプリURLをブックマークします

このURLを開くと、スプレッドシートを開かなくても管理画面だけを表示できます。
権限はGoogleアカウント側で管理されるため、URLを知っていても権限のない人は編集できません。

## 運用の流れ

1. 「写真登録」で写真とタイトル、スポット、タグを入れます
2. 追加された写真は非公開で保存されます
3. 「承認」画面で内容を確認し、「承認する」を押します
4. 「写真管理」でキャプションや表示状態を調整します
5. 平日9時・12時・17時の自動更新、またはGitHub Actionsの手動実行で公開されます

## 写真管理の考え方

- 「表示」をOFFにすると、その写真は公開サイトに出ません。
- 「ダウンロード対象」をOFFにすると、その写真は公開サイトの写真一覧・スポットページに出ません。
- 公開サイトには「表示ON」かつ「ダウンロード対象ON」の写真だけが反映されます。
- キャプションは写真カードやスポットページの写真下に表示される文言です。

## 注意

- 管理画面はスプレッドシートを編集できる人だけが使える想定です。
- 誤公開を防ぐため、新規写真は最初から公開せず、必ず承認待ちにします。
- スプレッドシートの列名は変えないでください。管理画面も自動更新も同じ列名を使います。
- 管理画面を初めて開くと、「写真」タブに `downloadAllowed` 列が自動で追加されます。既存写真はTRUEになります。
