# 資料フォルダ

このフォルダは、SHIKA PHOTO LIBRARY の運用資料を用途別に整理したものです。

## 🔗 よく使うリンク

| 何を開きたいか | リンク |
|---|---|
| 公開サイト | <https://shika-town.github.io/photo-library/> |
| 運用スプレッドシート | <https://docs.google.com/spreadsheets/d/1A9_xzFMdD-UhKyo_a7xJ2h-5cM-orZ_giXX41ZiKT3Y/edit> |
| 管理画面（写真登録・承認・スポット編集） | スプレッドシート上部メニュー「フォトライブラリー管理」→「入力画面を開く」 |
| 今すぐサイトに反映させたいとき | <https://github.com/shika-town/photo-library/actions/workflows/publish.yml> →「Run workflow」 |
| GitHubリポジトリ | <https://github.com/shika-town/photo-library> |

初めての方・写真を登録したいだけの方は、まず [`01_担当者向け/担当者マニュアル_フォトライブラリー管理画面.md`](01_担当者向け/担当者マニュアル_フォトライブラリー管理画面.md) だけ読めば作業できます。

## よく使う資料

| 対象 | ファイル |
|---|---|
| 写真を編集する担当者 | `01_担当者向け/担当者マニュアル_フォトライブラリー管理画面.md` |
| 管理者・保守担当 | `02_管理者向け/管理者マニュアル_フォトライブラリー運用保守.md` |
| 管理画面の設置・更新 | `02_管理者向け/管理画面_設置手順.md` |

## フォルダの意味

| フォルダ | 内容 |
|---|---|
| `01_担当者向け/` | 日々の写真登録・修正・承認に使う資料 |
| `02_管理者向け/` | 管理画面、Apps Script、GitHub Actions の保守資料 |
| `03_初期設定/` | 初期構築時の手順。通常運用ではほぼ使いません |
| `04_チェックリスト/` | 公開前や確認作業用のチェックリスト |
| `05_設計資料/` | 初期設計・仕様書・ワイヤーフレーム |
| `06_旧資料/` | 旧Excelや台帳など、念のため残す資料 |

`03_初期設定/` 以降は庁内向け・初期構築向けの資料を含むため、GitHubには上げない運用です。
